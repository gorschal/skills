# AGENTS.md / CLAUDE.md — документация для агентов

Память проекта для AI-агентов: **opencode** (и ряд инструментов) читает `AGENTS.md`,
**Claude Code** — `CLAUDE.md`. Если используются оба — **оба файла должны
существовать и быть синхронизированы**. Принцип жёсткий: **кратко и проверяемо**.
Лишний контекст вредит — агент тонет в воде и игнорирует важное.

## Что писать (и чего НЕ писать)

**Писать** — то, что агент не выведет сам и что проверяемо:

- как запускать/тестировать/линтить (конкретные команды);
- нерушимые правила и ограничения («миграции — только Django», «секреты из env»,
  «не трогать `legacy/`»);
- неочевидные соглашения (структура модулей, формат ошибок RFC 7807, стиль коммитов);
- ссылки на canonical docs (ARCHITECTURE.md, ADR) — указатель, не пересказ;
- Definition of Done, если есть.

**НЕ писать:** пересказ кода, общие фразы («пиши чистый код»), длинные объяснения,
дубли README, неактуальные заметки. Непроверяемое правило бесполезно.

## Правило проверяемости

Каждый пункт — **проверяемый командой или явным гейтом**. «Пиши качественно» — мусор.
«Перед коммитом: `ruff check && pyright && pytest`» — правило.

## Скелет (1–2 экрана)

```markdown
# Project — заметки для агента

## Стек и запуск

- Python 3.12, Django/FastAPI, Postgres, Redis. Пакеты: uv.
- dev: `uv run python manage.py runserver` · тесты: `uv run pytest` · линт: `uv run ruff check .`
- миграции: `python manage.py migrate` (перед прод — навык `migration-safety`).

## Правила (нерушимые)

- Секреты только из env (`pydantic-settings`), не в коде/репозитории.
- Бизнес-логика — в `services/`, не во views/роутерах.
- Не редактировать применённые миграции; схема — Django.

## Definition of Done

- `ruff check`, `ruff format --check`, `pyright`, `pytest` зелёные.
- Публичные API имеют docstring; FastAPI-эндпоинты — English (ReDoc).
- Нетривиальное решение зафиксировано в `docs/adr/`.

## Канонические доки

- Архитектура: docs/ARCHITECTURE.md · Решения: docs/adr/
```

## Синхронизация AGENTS.md и CLAUDE.md

Два файла с одинаковым содержанием расходятся со временем — **HIGH-риск** (агенты
получают разные правила). Варианты по надёжности:

1. **Symlink:** `AGENTS.md` → `CLAUDE.md` (или наоборот). Не переносимо везде
   (Windows), но один источник правды.
2. **Один источник + тонкий указатель (рекомендую):** правила в `AGENTS.md`, а
   `CLAUDE.md` содержит `See AGENTS.md — single source of truth`.
3. **Копия + diff в CI/аудите:** оба файла — копии; сверять расхождение.

Выбор зафиксировать в ADR. Если используется только opencode — достаточно `AGENTS.md`.

## Аудит agent-docs

- **CRITICAL:** указана команда/путь, которых уже нет → агент сломает прод.
- **HIGH:** есть только один из двух файлов (если нужны оба); файлы рассинхронизированы.
- **MEDIUM:** непроверяемые правила; раздутый файл; нет ссылок на canonical docs.
- **LOW:** стиль, дублирование README, устаревшие мелочи.
