## Принципы

- **Вердикт первым**, потом детали.
- **Конкретика:** файл, строка, проблема, решение.
- **Приоритизация:** критичное → важное → nice-to-have.
- **Баланс:** сильные стороны обязательны.
- **Соразмерность:** требования к стадии проекта.
- **Без эмодзи.**
